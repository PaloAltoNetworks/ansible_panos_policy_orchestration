# Running in Ansible Automation Platform

Running this collection in an AAP environment is straightforward. Take a look at an [example repository](https://github.com/adambaumeister/ansible-panos-policy-automation-demo) which can be 
used as a "project" in AAP, and use our published Execution Environment image:

```
ghcr.io/paloaltonetworks/panos_policy_automation-rhel9:feat-ansible-ee
```
